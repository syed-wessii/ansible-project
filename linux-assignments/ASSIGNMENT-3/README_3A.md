# Linux Assignment 3A – Pattern Printing

## Objective
Create a Bash script that prints different star (`*`) patterns using nested `for` loops.

## File
`assignment3a.sh`

## How to Run
```bash
chmod +x assignment3a.sh
./assignment3a.sh
```

Or:
```bash
bash assignment3a.sh
```

## Verification

Check the file:
```bash
ls -l assignment3a.sh
```

Check syntax:
```bash
bash -n assignment3a.sh
echo $?
```

Run the script:
```bash
./assignment3a.sh
```

The script should print all required star patterns without errors.
